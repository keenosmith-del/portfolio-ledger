# Verified application description

PortfolioLedger is my independent backend engineering demonstration for property-finance operations. I built a typed Python/FastAPI service with PostgreSQL, SQLAlchemy and Alembic, plus an authenticated React interface. Two fictional provider formats feed a durable import worker that records provenance, quarantines invalid rows and handles replay without duplicating financial postings. The rental ledger preserves corrections through reversal and replacement entries. Reconciliation retains source evidence and audited review decisions, while versioned administration-fee previews use Decimal calculations, explicit date boundaries and immutable snapshots. Verification includes PostgreSQL integration and concurrency tests, worker crash recovery, a real browser workflow and a measured 10,000-event import/replay. The application runs locally with Docker Compose. Development decisions, actual defects and passing reruns are documented alongside incremental Git commits. It contains only synthetic data and makes no claim of a real provider integration or public deployment.
