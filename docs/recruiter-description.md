PortfolioLedger is a PostgreSQL-first synthetic property-finance application built with FastAPI, React and TypeScript. It normalizes two fictional provider formats into an append-only Decimal ledger, preserving source evidence and reversal/replacement lineage. A durable worker supports recoverable imports, quarantine and idempotent replay. Users can reconcile discrepancies, record audited reviews, calculate reproducible administration-fee previews and export CSV. The refreshed interface supports desktop, tablet, mobile and keyboard use. Release controls include registered sources, scoped read-only review, CSRF protection, strict production settings and separate database roles. Repeatable local verification covers financial invariants, browser workflows, 10,000-event replay, backup restoration and operational recovery. Public hosting remains unverified.
